How to parse natural language without an LLM

Drop any text in. It is read the way the fold reads it — then the reading is replayed, one layer at a time: bytes → decode → furniture → statements → tokens → grammar → morphology → referents → relations → ledger → priors. Every layer is the fold's own vendored code, running here in your browser. No language model is called at any point. Every name is the giver that supplied it, every claim is anchored to the bytes it was read from, and every assertion stays revisable. Start with Propositions: the source itself, with each proposition it makes drawn out.
