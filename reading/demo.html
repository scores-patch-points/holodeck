How to read without a model — the pipeline, layer by layer

Drop any text in. It is read the way the fold reads it — and you can watch every layer do its work, then switch a layer off and see exactly what it was carrying. The pipeline: bytes → decode → furniture → statements → words → POS → morphology → stance → referents → relations → render → EOT. Every organ is the fold's own vendored code, running here in your browser. No language model is called at any point — and the page counts every network request to prove it. Every name is the giver that supplied it, every claim is anchored to the bytes it was read from, and every assertion stays revisable.

Propositions shows the source in reading order with each proposition drawn as subject —act→ object, carrying a confidence derived from the engine's own signals. POS / Morphology open the priors that did the work. Render shows the same triple in English (SVO), SOV and VSO. EOT is the folded, append-only ledger. Switch any layer in the left rail off and the reading re-runs — with the cost disclosed. A PDF is read through its own text layer (pdf.js); an image, a recording or a binary file is refused with a typed gap, never decoded into mojibake — the full holodeck reads those with its own visual model, OCR and ASR.
